名人堂人物图片
================
把人物照片按下面 id 命名后放到本目录，游戏里就会自动显示；
没有图片时显示书法字牌头像（不影响游戏）。

文件命名：<id>.jpg（也支持 .png）

id 对照：
  yiqiu          弈秋（先秦，无传世画像）
  wangjixin      王积薪（唐代）
  huanglongshi   黄龙士（清代棋圣）
  fanxiping      范西屏（清代）
  shixiangxia    施襄夏（清代）
  daoce          本因坊道策（日本）
  xiuce          本因坊秀策（日本）
  wuqingyuan     吴清源
  nieweiping     聂卫平
  ruinaiwei      芮乃伟
  lichanghao     李昌镐
  lishishi       李世石
  kejie          柯洁
  shenzhenxu     申真谞

提示：图片会以圆形头像显示（object-fit: cover），建议使用方形照片。
