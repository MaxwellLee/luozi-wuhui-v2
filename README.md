# 落子无悔 · 与柯洁老师学围棋

一款**新手友好**的围棋学习对弈游戏：不会下棋也没关系，柯洁老师会手把手教你规则、在实战中给你支招。

> 🕹 **在线试玩（GitHub Pages）**：https://maxwelllee.github.io/luozi-wuhui/

## 🚀 快速开始

1. 双击 `index.html`（推荐 Chrome / Edge 浏览器），或双击 `Play.bat`
2. 首次打开建议先逛 **围棋课堂**（5 节互动规则课），再点 **开始对局**
3. 全程离线运行，无需联网、无需安装

> 提示：背景音乐需要先点击一下页面（浏览器策略），音效/音乐/曲目可在「设置」里调节。

## ✨ 功能一览

### 对局
- **正式对局 · 猜先**：柯洁老师抓一把白子，你猜单双决定执黑执白（中国围棋礼仪）
- **快速练习**：自选黑白、让先 / 让 2~9 子，可随时悔棋
- 9 / 13 / 19 路棋盘；**中国规则**：黑贴 3¾ 子，终局点目、标记死子自动数子
- **四档 AI**（启蒙 / 入门 / 进阶 / 挑战），对局中随时切换
- 「请指教」推荐落点并讲解；危险落子（填眼、禁着、打劫）自动提醒
- 柯洁老师逐手点评；自动存档，下次可「继续对局」

### 学习
- **围棋课堂**：5 节互动课（棋盘 → 气与提子 → 禁着与劫 → 眼与死活 → 终局胜负），含演示动画、亲手做题、小测验
- **棋谱库**：入门棋谱 / 名局片段（吴清源星·三三·天元、秀策流、中国流、李世石「神之一手」）/ 我的对局回放，支持 SGF 导入导出
- **围棋故事**：四千年历史时间线、14 位名人堂、成语典故、棋品九品、礼仪与冷知识

### 视觉与声音
- 三款纹理皮肤：**和风木韵**（暖）/ **落日枫林**（橙）/ **星夜墨竹**（暗）
- 动漫风头像：你的角色（儒雅棋友）vs 柯洁老师（圆框眼镜少年棋士），随局势切换表情
- 落子 / 提子 / 胜利音效 + 4 首五声音阶合成纯音乐（竹涧、松风琴语、星河入梦、空山雨后）

## ❓ 常见问题

- **数据存在哪？** 浏览器本地（localStorage）。换浏览器或清除浏览器数据会丢失；可在「设置 → 导出全部对局」备份。
- **AI 有多强？** 定位为「新手陪练到业余爱好者」水平，不是职业级引擎。
- **名局棋谱准确吗？** 名局片段为「关键片段 + 故事讲解」，个别角位按史料校订/标注为示意。
- **名人堂图片？** 开发环境无外网、无法代下载真人照片。已预留图片位：把照片命名为 `img/figures/<id>.jpg` 放入即可显示（id 对照见该目录 README.txt）；没有图片时显示书法字牌头像。
